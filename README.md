# ppr-media

Media files for the Parking Position Rec. website (parkingpositionrecords.tilda.ws).

| File | What it is |
|---|---|
| `ppr-hero.webm` / `ppr-hero.mp4` | 24 s looping background montage for the LED departures board (Lost.Act on tour), 960×540, no audio |
| `ppr-hero-poster.jpg` | Still frame shown while the video loads |

The site loads these files directly from this repository, so keep the file names when replacing them.
